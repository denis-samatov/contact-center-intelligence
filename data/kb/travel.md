# Страхование для путешествий (Демо-Страхование, вымышленные правила)

## 1. Покрытие
Полис для путешествий покрывает экстренную медицинскую помощь, госпитализацию и медицинскую транспортировку.

## 2. Франшиза
Для тарифа «Эконом» действует франшиза три тысячи рублей. Тариф «Комфорт» без франшизы.

## 3. Обращение
При наступлении случая за границей нужно сначала позвонить в сервисную компанию по номеру из полиса, а затем обращаться в клинику.
